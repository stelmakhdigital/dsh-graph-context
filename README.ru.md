# dsh-context-graph

Нативный плагин [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): **локальный контекстный граф** репозитория (движок — внешний CLI [`@nanonets/graft`](https://www.npmjs.com/package/@nanonets/graft)) — инструменты модели + жизненные циклы контекста + fail-open.

Модель получает точные указатели `file:line`, сигнатуры без тел и трассы вызовов вместо слепого grep/read. Всё работает локально через CLI `@nanonets/graft`: индекс никуда не уходит, LLM плагин никогда не вызывает.

## Требования

- Node.js **22.19+ / 24+** (ESM, TypeScript strict)
- DSH с профилем, поднимающим Cordis-бандлы (web / headless / tui / …)
- CLI движка один раз на машине:

  ```sh
  npm i -g @nanonets/graft
  ```

  Плагин также умеет fallback на `npx -y @nanonets/graft` (медленный первый вызов) и позволяет зафиксировать бинарь через `graphPath` / `GRAPH_CLI`. Без CLI плагин полностью инертен (fail-open, см. ниже).

## Установка

```sh
dsh plugin --profile web add dsh-context-graph   # из реестра, когда опубликуем
# или из чек-аута:
dsh plugin --profile web add /path/to/dsh-graph-context
```

Форвардер `dsh plugin` линкует пакет в профиль и автоматически добавляет `dsh-context-graph` в стек бандлов профиля (пакет декларирует `dsh.bundle.patch`). При каждом старте оверлей из `cordis.patch.yml` применяется заново.

> **Каждый клон строит свой индекс.** Граф — per-repo (каталог `graft/`, CLI добавляет его в .gitignore). При `autoBuild: true` (по умолчанию) плагин запускает `graft build` в фоне на старте сессии, если у репо графа ещё нет — только структурное индексирование, без LLM и без сети.

## Что делает

| Инструмент | Назначение |
| --- | --- |
| `graph_repo_map` | Ориентация: кластеры каталогов, хаб-символы, глобальные hotspot'ы. Первый вызов в незнакомом репо. |
| `graph_find_code` | Вопрос / символ / сообщение об ошибке → ранжированные указатели `file:line` (+ `source: true` инлайнит суть). |
| `graph_file_api` | Сигнатуры файла без чтения его тела. |
| `graph_trace_calls` | Калл-сайты (`direction: in`) или вызовы (`out`) символа; `depth > 1` — транзитивно (blast radius). |
| `graph_find_all` | Регулярка по проиндексированным источникам, ранжирование по связанности. |
| `graph_check_freshness` | Отчёт о дрейфе после правок; `stale` → выполнить `graft build`. |
| `graph_blast` | Blast radius диффа (P2c): затронутые символы + downstream-зависимости git-diff (рабочее дерево vs HEAD, или `base` ref, напр. `origin/main`). Бесплатно (без LLM). |

Плюс жизненный цикл, повторяющий push-цикл Claude-Code — ориентация *подталкивается* в контекст, а не только через pull-инструменты:

- **Секция системного промпта** (5–15 стабильных строк): граф существует, вот нативные инструменты, вызывать их до широкого grep; инструкции по fallback, когда граф/CLI отсутствуют.
- **Inject на старте сессии** (`agent/session-start`): отрендеренная карта репо (ограничена байтами, по умолчанию 4096 B) ставится в очередь *на следующий* запрос через `agent.inject` — модель не «просыпается». Если `graft/` ещё нет, один структурный build запускается в фоне под lock репо, а вместо карты инжектится короткий «собирается»-указатель.
- **Retrieval на промпт** (`agent/pre-step`): если промпт ≥ `promptMinChars`, плагин выполняет `graft ask … --json -n 3` (только указатели, без тел кода) и дописывает топ-хиты коротким контекстным сообщением к ходу. Один и тот же топ-хит в одной сессии/репо повторно не инжектится, идентичный промпт не гоняется по CLI повторно.
- **Blast radius после правок** (`tools/post-execute`): если edit-инструмент (`editToolNames`) принял файл исходников (не `graft/`), граф помечается dirty и — если blast radius короткий — «кто зависит» дописывается через `additionalContexts`.
- **Авто-синхронизация на остановке хода** (`agent/turn-stopping`): если граф dirty на момент остановки хода, один структурный `graft build` запускается в фоне под lock репо — без блокировки хода.
- **User-level скилл**: при загрузке плагин один раз устанавливает `skills/graph/SKILL.md` в `$DSH_HOME` (идемпотентно; кастомизированный файл не перезаписывается) — словарь инструментов доступен модели ещё до первой карты.

Каждый канал fail-open: нет git / нет CLI / нет `graft/` / таймаут / битый JSON — агентный цикл не затрагивается, хук никогда не бросает исключение в loop.

P2a уточняет push для локальных моделей, каждое — за своим флагом:

- **Sourced retrieval по умолчанию** (`injectMode: sourced`): pre-step pack инлайнит crux топ-хита ≤8 строк (`graft ask --source`), а не только `file:line` — мелкие модели часто не делают follow-up-вызов, поэтому crux приходит сразу. `pointers` — компактное поведение Sonnet-style; `map-only` — pre-step retrieval выключен полностью.
- **Напоминание, а не запрет** (`nudgeOnBlindSearch`): широкий `grep`/`glob` (без сужения path) до любого graph-вызова ставит одно короткое напоминание в очередь на следующий запрос — сам поиск никогда не блокируется.
- **Scope для монорепо** (`scopeFromLastEdit`): после правки следующий retrieval сужается (`ask --in <top-level-dir>`) до каталога последнего отредактированного файла. Подсказка — *относительный* путь (слабость движка с basename исправлена здесь).
- **Локальные метрики** (`metrics`): принятые graph-чтения против сырых source-чтений по сессии пишутся в `$DSH_HOME/context-graph-stats.json` — только локальный файл, ничего нигде не POSTится (см. Приватность).
- **Wiring-guard** (`guardWiringReads`, opt-in): прямое чтение `graft/.graph/*` отклоняется с указателем на tools `graph_*`.

## Конфигурация

Значения по умолчанию в бандл-оверлее (`cordis.patch.yml`) включают весь стек; строка `config: {}` оставляет всё как есть. Все поля:

| Ключ | По умолчанию | Смысл |
| --- | --- | --- |
| `tools` | `true` | Регистрировать шесть инструментов `graph_*`. |
| `injectSessionMap` | `true` | Инжектить карту репо на старте сессии. |
| `injectPromptHits` | `true` | (P1) хиты retrieval на промпты пользователя. |
| `injectBlastRadius` | `true` | (P1) blast radius после правок исходников. |
| `autoBuild` | `true` | Запускать `graft build` на старте сессии, если графа нет. |
| `autoSync` | `true` | (P1) пересборка на остановке хода при dirty. |
| `maxInjectBytes` | `4096` | Жёсткий потолок в байтах на один инжект. |
| `promptMinChars` | `12` | (P1) мин. длина промпта для retrieval. |
| `graphPath` | `''` | Явный бинарь движка (путь или имя в PATH). Пусто → бинарь `graft` в PATH → fallback на `npx`. Учитывается env `GRAPH_CLI`. |
| `timeoutMs` | `8000` | Таймаут запроса. |
| `buildTimeoutMs` | `20000` | Таймаут структурной сборки. |
| `deep` | `false` | Флаг LLM-прохода; хуки его никогда не используют — только явные команды пользователя. |
| `editToolNames` | `["write","edit"]` | (P1) имена хост-инструментов, помечающих граф dirty. |
| `injectMode` | `sourced` | (P2a) форма pre-step retrieval: `sourced` (топ-хит с crux ≤8 строк + связанные указатели — DSH-дефолт для локальных моделей), `pointers` (только компактные указатели) или `map-only` (pre-step retrieval выключен; единственный push — карта сессии). |
| `nudgeOnBlindSearch` | `true` | (P2a) одноразовое напоминание, если модель пошла в широкий grep/glob, не вызвав ни одного graph-инструмента. Никогда не блокирует. |
| `scopeFromLastEdit` | `false` | (P2a) сузить следующий pre-step `ask` до top-level каталога последнего отредактированного файла (польза для монорепо; по умолчанию выкл, чтобы в одно-пакетных репо retrieval оставался по всему репо). |
| `metrics` | `true` | (P2a) локальные счётчики graph- vs source-чтений по сессии в `$DSH_HOME/context-graph-stats.json`. Только локально — никогда не POST. |
| `guardWiringReads` | `false` | (P2a) отказывать в прямом чтении `graft/.graph/*` с подсказкой на tools. Текстовая инструкция уже в system-секции и скилле; жёсткий guard — opt-in. |
| `injectSubagentMap` | `true` | (P2b) короткий repo-мап субагентам при `agent/created` (бюджет `maxInjectBytes / 2`), чтобы explore-субагент в репо с графом не повторял cold-grep родителя. |
| `reinjectAfterCompaction` | `true` | (P2b) после компакции истории хостом одноразово reinject короткого мапа на следующем pre-step — ориентация session-start переживает компакцию. |
| `toolOrder` | `true` | (P2b) graph-tools — первыми в собранном промпте (`system-prompt/assemble`); no-op, если хост не отдаёт событие. |
| `blastOnResume` | `true` | (P2c) при RESUME сессии с грязным рабочим деревом — короткий diff-blast («что может сломать этот незакоммиченный код»). |

Оверлей пользователя (патч заменяет **весь** конфиг строки — переписывайте все ключи, которые хотите сохранить), например из `cordis.yml.example`:

```yaml
- insert:
    - id: context-graph
      name: 'dsh-context-graph'
      inject: ['tools', 'systemPrompt']
      config:
        tools: true
        # …все остальные ключи переписаны…
        graphPath: '/usr/local/bin/graft'
        maxInjectBytes: 8192
```

## Fail-open контракт

Хуки никогда не бросают исключения в цикл агента, инструменты никогда не reject: инфраструктурные проблемы превращаются в стабильный код `error` внутри (замкнутого) значения инструмента.

| Код | Смысл | Что делать модели |
| --- | --- | --- |
| `GRAPH_CLI_MISSING` | CLI движка не найден | Fallback на read/grep; hint предлагает `npm i -g @nanonets/graft`. |
| `GRAPH_MISSING` | Нет индекса `graft/` от cwd сессии | Подождать фоновую сборку / выполнить `graft build`. |
| `GRAPH_TIMEOUT` | Запрос или сборка превысили бюджет | Повторить один раз, потом fallback. |
| `GRAPH_BAD_JSON` | Вывод CLI не распарсился | Fallback; проверить версию CLI. |
| `GRAPH_FAILED` | Любая другая ошибка spawn/CLI | Fallback на обычные инструменты. |

Нет git-репо → плагин полностью молчит (ни ошибок, ни инжектов, ни логов). Меж-сессионная координация сборок — через lock-файл на репо (`.dsh-context-graph-build.lock`): N сессий, стартовавших в одном репо, запускают ровно одну сборку; просроченные lock'и (старше таймаута + 30 c, мёртвый pid) перехватываются.

## Приватность и телеметрия

- CLI запускается с явным минимальным окружением: `PATH`, `HOME`/`USERPROFILE` (если заданы) и `DO_NOT_TRACK=1`. API-ключи и ambient-окружение не пробрасываются.
- Структурный `graft build` не делает сетевых вызовов. Опциональный LLM-проход (`--deep`) плагином никогда не триггерится.
- Сторонняя телеметрия от самого плагина отсутствует.
- **Инвариант: граф не секретнее исходников.** `graft/` содержит выдержки кода; плагин не отправляет содержимое репо никуда — в хуках вообще нет сетевых примитивов (принудительно стат-сканом в тестах), а счётчики `metrics` пишутся только в локальный `$DSH_HOME`.

## Взаимное исключение с MCP-сервером движка

**Не** регистрируйте MCP-сервер движка рядом с этим плагином: поверхности пересекаются (нативные `graph_*` и MCP-имена с префиксом внешнего движка), дублирующая поверхность путает модель и удваивает работу индекса. Выберите одну поверхность на профиль — нативный плагин является рекомендуемой (в комплекте жизненные циклы).

## Языки и сосуществование

- **Покрытие языков** — в этом стеке движок полнокровен для TypeScript/JavaScript; поддерживаются Python и Go, неизвестные языки пропускаются штатно. Плагин не обещает 100% покрытие — нераспознанный файл просто не даёт узлов в графе. (Опциональный LSP-проход, например pyright/tsserver, в P0–P2a не подключён; это тяжёлый opt-in spawn за будущим флагом.)
- **vs `dsh-web-automation`** — это отдельный пакет для *веб*-поиска; этот плагин — для поиска *в репо*. Разные имена инструментов, конфликта нет; в одном профиле сосуществуют.

## Диагностика

- **Инструменты сообщают `GRAPH_CLI_MISSING`** — `npm i -g @nanonets/graft` (или задать `graphPath`). Сессия работает штатно без графа.
- **`GRAPH_MISSING` держится после старта сессии** — фоновая сборка ещё идёт (большие репо); проверьте `graft check` или выполните `graft build` вручную.
- **Два репо, две сессии** — каждая сессия разрешает репо от *своего* session cwd (заголовка сессии); графики не пересекают границы репо. Session-start хук дополнительно требует, чтобы session cwd был на месте: если его нет, хук молчит, а не угадывает каталог запуска сервера (v0.1.1).
- **Лишний файл `.ignore` в корне репо** — это артефакт движка (возвращает за-игноренные карточки `graft/` в поиск ripgrep), не плагина. При желании добавьте его в `.gitignore`.
- **Устаревший граф** — `graph_check_freshness` покажет дрейф; `graft build` (структурный) его обновит.

## Дорожная карта

P0 (выпущено): пакет + оверлей + 6 инструментов + секция системного промпта + session-start map inject + autoBuild + fail-open.
P1 (выпущено, v0.2.0): retrieval хитов на промпты (`agent/pre-step`), blast radius после правок (`tools/post-execute`), autoSync на остановке хода, dirty-трекинг, установка user-level скилла, settings-секция (если хост монтирует провайдера).
P2a (выпущено, v0.3.0): `injectMode` (sourced/pointers/map-only), nudge при слепом поиске, mono-repo scope по последней правке, локальные метрики, wiring-охрана, тест инварианта приватности.
P2b/P2c (каждое — свой флаг): хост-поверхности (compaction re-inject, subagent-карта, порядок инструментов), затем тяжёлые фичи (`graph_blast`, local `--deep` enrich, watcher, Code Mode).

Гейты и критерии приёмки — в `roadmap.md`.
